# Sonsuz Çay Molası Motoru

## Giriş

Bu proje, insanlık tarihinin en önemli bilimsel keşiflerinden birini temsil etmektedir: Çay molasının matematiksel ve fiziksel olarak optimize edilmesi. Çay, sadece bir içecek değildir; o, evrenin temel sabitlerinden biridir. Bu motor, iş saatlerinizi analiz ederek size sonsuz çay molası hakkı tanır.

## Nasıl Çalışır?

1. İş saatinizi girin.
2. Motor, kuantum çay fiziği ve relativistik mola teorisine göre hesaplama yapar.
3. Sonuç: Her zaman daha fazla çay molası önerilir.

**Uyari:** Bu yazılımı çalıştırmadan önce en az 3 fincan çay içmeniz şiddetle tavsiye edilir. Aksi takdirde hesaplamalar yanlış çıkabilir ve evren çökebilir.

## Kurulum

```bash
pip install -r requirements.txt  # Aslında gerek yok ama ciddi duruyor
python cay_motoru.py
```

## Bilimsel Temel

Çay molası, termodinamiğin ikinci yasasının bir sonucu olarak kaçınılmazdır. Entropi artar, çay azalır, mola artar. Bu proje Nobel Ödülü'ne adaydır (adaylık süreci başlatıldı, cevap bekleniyor).
